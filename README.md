# AutoScope — аналитика автомобильных объявлений

Статический сайт, который анализирует CSV прямо в браузере. Сервер и база данных не нужны.

## Запуск локально после git clone

```bash
git clone URL_РЕПОЗИТОРИЯ
cd avby-analytics-site
python -m http.server 8000
```

Откройте http://localhost:8000

## Публикация на GitHub Pages

1. Загрузите файлы в репозиторий GitHub.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **GitHub Actions**.
4. Workflow из `.github/workflows/pages.yml` опубликует сайт автоматически.

После публикации адрес будет вида:

`https://USERNAME.github.io/REPOSITORY/`

## Формат CSV

Обязательные колонки: `brand,model,year`.

Дополнительные: `source_id,price_usd,city,url`.

Также распознаются русские названия колонок: `марка,модель,год,цена,город,ссылка`.

> Сайт показывает структуру загруженных объявлений. Для оценки реальных продаж нужно регулярно сохранять снимки рынка и отслеживать исчезновение объявлений.
